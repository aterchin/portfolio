Quick how-to to create a custom action in SourceTree.  I was needing to create a zip file of a specific commit in SourceTree.  The point of the package was to send only modified files in the correct hierarchical directory for deployment to a server while I was out on PTO and I wanted the package to be easy to unzip over just the modified files.  Not a full git archive, just the modified files to be unzipped at the root of the project.


## SourceTree Custom Action

You can trigger this directly from SourceTree's UI by right-clicking a commit.

### Step A: Create a reusable script file

SourceTree executes external scripts. Create a script named `git-zip-commit.sh` in a safe location (e.g., your home folder):

```bash
# Ensure we have a commit hash
if [ -z "$1" ]; then
    echo "Error: No commit hash provided."
    exit 1
fi

COMMIT_SHA="$1"

# 1. Added "-m" to support merge commits
# 2. Capture the file list into a variable first
FILES=$(git diff-tree -r --no-commit-id --name-only --diff-filter=d -m "$COMMIT_SHA")

# Check if the file list is empty
if [ -z "$FILES" ]; then
    echo "Error: No modified files found for commit $COMMIT_SHA."
    echo "This prevents zipping the entire repository by mistake."
    exit 1
fi

# Run the archive command only with the specific files
git archive -o patch.zip "$COMMIT_SHA" $FILES

echo "Success! Created patch.zip with only modified files."

```

Make the script executable by running this in your terminal:

```bash
chmod +x /path/to/git-zip-commit.sh
```

### Step B: Configure SourceTree

1. Open SourceTree and go to Tools \> Options (Windows) or SourceTree \> Preferences (Mac).
2. Click on the Custom Actions tab.
3. Click Add.  
4. Fill out the fields:  
* Menu Caption: **Zip Commit for Deployment**  
  * Script to Run: Select your `git-zip-commit.sh` file.  
  * Parameters: `$SHA`
5. Click OK.
