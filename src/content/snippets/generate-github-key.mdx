summary: Generate a SSH key for GitHub on your server
---

```bash
# Generate key on server
ssh-keygen -t ed25519 -C "username@example.com"

# enter file in which to save the key (or accept the defaults)
/home/user_name/.ssh/id_ed25519_username
```
Next, copy the contents of `~/.ssh/id_ed25519_username.pub` and add it to the SSH and GPG keys section in your GitHub Account Settings.

## Test it

Try to pull from your repo.  If it still asks for a username and password, your repository is likely still configured to use an HTTPS URL instead of an SSH URL.

Change your remote URL to SSH:

```
git remote set-url origin git@github.com:username/repo.git
```

Replace `username/repo.git` with your actual repository path.

## Troubleshooting

### Error: "Permission denied (publickey)."

Try addding your key to the agent by running ssh-add `~/.ssh/id_ed25519_username`.

### Error: "Could not open a connection to your authentication agent."

SSH agent isn't running in your current terminal session.  Start the agent:

```
eval "$(ssh-agent -s)"
```

Once started, re-run ssh-add `~/.ssh/id_ed25519` to add your key.
