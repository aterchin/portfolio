## View IP and adapters

Get your public IP.

```bash
curl ifconfig.me

# IP v4
curl -4 ifconfig.me
```

Get your local (Private) IP instead.

**macOS**

```bash
# All adapters and details
ifconfig

# Primary Wi-Fi IPv4 only
ipconfig getifaddr en0
```

**Windows**

```bash
ipconfig

# Or using modern PowerShell:
Get-NetIPAddress
```

## Test a TCP port

Check whether a host accepts TCP connections on a given port.

**macOS**

```bash
nc -vz <address> <port>
```

**Windows**

```bash
Test-NetConnection <address> -Port <port>
```

## Ping (ICMP)

Verify that a host responds on the network.

**macOS**

```bash
# Runs until stopped with Ctrl+C
ping 8.8.8.8

# Limit to 4 packets (Windows default)
ping -c 4 8.8.8.8
```

**Windows**

```bash
# Stops automatically after 4 packets
ping 8.8.8.8
```

## Trace route

Show the hop path and transit delays to a host.

**Windows**

**macOS**

```bash
traceroute google.com
```

```bash
tracert google.com

# Or using modern PowerShell:
Test-NetConnection google.com -TraceRoute
```

## DNS lookup

Resolve a hostname or query DNS records.

**macOS**

```bash
nslookup google.com

# Preferred for scripts (cleaner output):
dig google.com
```

**Windows**

```bash
nslookup google.com

# Or using modern PowerShell:
Resolve-DnsName google.com
```

## Active connections

List open TCP connections, listening ports, and routing tables.

**macOS**

```bash
netstat -an

# See which process owns a port (e.g. port 80):
lsof -i :80
```

**Windows**

```bash
netstat -an

# Or using modern PowerShell:
Get-NetTCPConnection
```

## Routing table

Display the kernel routing table.

**macOS**

```bash
netstat -nr
```

**Windows**

```bash
route print
# Or using modern PowerShell:
Get-NetRoute
```
