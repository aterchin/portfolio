Quick reference for commands to update remote URLs.  My company switched Bitbucket workspaces and the script made it easier to update. 

## The script

The commands are the same if you're not batch-updating.  Save this as `switch_repo.sh` in the root of your local repository.

Make it executable with `chmod +x switch_repo.sh` and run the script.

```bash
#!/bin/bash

# Replace with the new remote URL
NEW_REMOTE_URL="git@bitbucket.org:new-workspace/new-repo.git"

echo "Updating remote origin to: $NEW_REMOTE_URL"

git remote set-url origin "$NEW_REMOTE_URL"
git remote set-url --push origin "$NEW_REMOTE_URL"

echo "Verifying new remote configuration:"
git remote -v

echo "Fetching from origin..."
git fetch origin

echo "Done. You can now proceed with your git operations."
```
