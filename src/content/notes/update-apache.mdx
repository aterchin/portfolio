## RHEL

RHEL 8, 9, and 10 ship httpd via Application Streams. Supported versions are listed in the [Red Hat Application Streams life cycle](https://access.redhat.com/support/policy/updates/rhel-app-streams-life-cycle).

Check for updates:

```bash
sudo dnf check-update httpd
```

If a newer version is listed, apply it:

```bash
sudo dnf update httpd
```

Confirm the installed version:

```bash
httpd -v
```

## Ubuntu

Refresh the index, then upgrade apache2:

```bash
sudo apt update
sudo apt upgrade apache2
```

Confirm the installed version:

```bash
apache2 -v
```

## Optional: list available httpd streams

On RHEL, list every stream dnf knows about:

```bash
sudo dnf module list httpd
```
